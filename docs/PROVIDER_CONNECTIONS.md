# GOV-03 — Provider Connections, first implementation

Control Configuration > Advanced / Provider Connections (superadmin only). The API checks real GitHub user identity and Vercel team identity, not operation scopes. The existing product discovery uses the same server-only credential resolver. The current user-token bootstrap is not the final multi-organization GitHub App flow.

Secure capture is enabled only when NIXINX_PROVISIONING_SECRET_PROJECT_ID equals FIREBASE_PROJECT_ID. The authorized operator must enable Secret Manager and pre-create nixinx-provisioning-github-token and nixinx-provisioning-vercel-token in Control's own project. Grant the actual Control runtime identity only secretmanager.versions.access and secretmanager.versions.add on those two secrets (or equivalent scoped roles); never on customer projects. Verify credential scopes independently. Set NIXINX_PROVISIONING_VERCEL_TEAM_ID once to the authorized team. No secret values in chat, FDV, Firestore, or frontend config. No change to the existing Firebase credential mechanism or IAM by this release.

Without the vault setting the existing global environment tokens continue to work; with it, no fallback, and both secrets must be populated through the UI before product discovery can run. Coordinate the one-time activation; do not replace existing production envs or rotate unrelated tokens. After verified migration, remove bootstrap env tokens in an authorized follow-up. No new client env or deployment per onboarding. The UI tests candidate identity before adding a version, reads back latest and writes sanitized audit. Concurrent credential rotation is not yet serialized, and a failure after addVersion can require reconciliation; no automated retry. Only the operator should rotate at a time. CI is not evidence of live IAM or Secret Manager access. Google Cloud/Firebase, Looker Studio Pro, Stripe, GitHub App credentials, durable client workflow and full permission testing remain pending. No cloud grant, secret creation, or token assignment made by this code commit.
