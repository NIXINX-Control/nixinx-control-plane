Superadmin production action on existing authorized intake, using fresh delegated credential and stored binding. Resource Manager projects.testIamPermissions queries five required metadata permissions and a fixed set of sensitive permissions without accessing documents, users or secrets. Project-level result is limited, not proof of exhaustive effective access, resource-specific restrictions or absence of access elsewhere. No cross-tenant resource requests or live revocation performed. Pending independent verification and explicit permission expansion before SDK config if needed.
