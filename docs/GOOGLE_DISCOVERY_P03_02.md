# P03-02 — Read-only Google discovery adapter

Internal library only; not a deployed endpoint or credential broker. Accepts a trusted, explicitly authorized project binding and short-lived delegated OAuth access token. Calls fixed official HTTPS endpoints for resource manager, Firebase project and web-app listing, billing link state, enabled APIs and database metadata. No Firestore documents, auth users, secret values, SDK key retrieval, IAM writes or resource creation. Returns sanitized metadata, not billing account identifier or credentials. Direct organization parent only in this increment; folder-based projects require verified ancestry support later. No fallback, incomplete or mismatched responses fail closed. Tests use mock responses, not live Google access.

Before exposing via Control UI/API, implement approved per-client authorization, trusted binding storage, token acquisition and revocation, server-side superadmin/tenant checks, audit, and actual API tests. Never accept arbitrary token from browser or use Firebase Admin credentials directly as a customer credential. No environment changes. Exact permissions to be verified with live delegated principal. See FDV P03 MMIC.
