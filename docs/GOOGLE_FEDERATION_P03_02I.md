# P03-02I — Corporate STS exchange probe

Uses the approved corporate pool/provider, exact production identity and official Google STS token exchange. The authenticated superadmin clicks a separate explicit probe in Provider Connections; production only, no token or target supplied by browser. Fixed trust binding is public configuration verified in P03-02H; future changes require reconciliation and review. Decoded claims are preflight only; STS validates signed OIDC credential and provider condition. No token is returned, persisted, logged, or cached, no client IAM/SA impersonation or data call. Existing Firebase Admin and Preview credential paths untouched. Unit tests simulate provider responses and verify denial cases; live test must run in actual Control production with authenticated operator. STS success establishes exchange, not client authorization or API access. Future per-client impersonation requires separately authorized binding and tests.
